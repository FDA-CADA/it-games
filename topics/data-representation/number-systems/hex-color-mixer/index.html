🎨 Hex Color Mixer

Mỗi màu trên web là 3 byte R, G, B, mỗi byte viết bằng 2 chữ số hex (00 → FF, tức 0 → 255). Ví dụ #FF5733 trên slide: R = FF = 255, G = 57 = 87, B = 33 = 51.

Every web colour is 3 bytes R, G, B, each written as 2 hex digits (00 → FF, i.e. 0 → 255). For example #FF5733 from the slides: R = FF = 255, G = 57 = 87, B = 33 = 51.

Chữ số hex bên trái nặng gấp 16 lần chữ số bên phải. Muốn đổi màu nhiều thì chỉnh chữ số bên trái trước.

The left hex digit weighs 16 times more than the right one. For big colour changes, adjust the left digit first.

Cách chơi

  • Pha màu: chỉnh 6 chữ số hex (▲/▼, cuộn chuột, hoặc gõ vào ô) để màu của bạn khớp màu mẫu. Bấm Kiểm tra để xem độ gần và gợi ý tăng/giảm cho từng kênh.
  • Càng ít lần kiểm tra, điểm càng cao (tối đa 50 điểm/vòng).
  • Đọc mã: cho một mã hex, chọn đúng màu trong 4 ô.
  • Nhớ: 00 là tắt hẳn, FF là sáng nhất. #FFFFFF là trắng, #000000 là đen.
  • Mix: adjust the 6 hex digits (▲/▼, scroll, or type in the box) until your colour matches the sample. Press Check to see how close you are and an up/down hint for each channel.
  • The fewer checks you use, the higher the score (up to 50 points per round).
  • Read: given a hex code, pick the matching colour out of 4.
  • Remember: 00 is fully off, FF is brightest. #FFFFFF is white, #000000 is black.
