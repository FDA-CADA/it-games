🔍 One Byte, Many Meanings

Bộ nhớ chỉ chứa bit. Cùng một byte 01000001 có thể là số 65, là chữ 'A', hay là một điểm ảnh xám tối. Ý nghĩa nằm ở cách diễn giải, không nằm trong bit.

Memory only holds bits. The same byte 01000001 can be the number 65, the letter 'A', or a dark gray pixel. Meaning lives in the interpretation, not in the bits.

Mỗi vòng, bạn nhìn một byte qua 4 "kính lọc" và đoán giá trị qua từng kính.

Each round you look at one byte through 4 "lenses" and work out its value through each one.

📋 Bảng tra nhanh
  • In two's complement the leftmost bit (128) is the sign bit: if it is 1, value = unsigned − 256.
  • ASCII uses only 7 bits (0–127). Anchors to remember: space = 32, '0' = 48, 'A' = 65, 'a' = 97. Codes 0–31 and 127 are control characters (not printable).
  • 8-bit gray pixel: 0 is pure black, 255 is pure white, 128 is mid-gray.
  • Bit trái nhất (128) là bit dấu trong two's complement: nếu bằng 1 thì giá trị = unsigned − 256.
  • ASCII chỉ dùng 7 bit (0–127). Mốc cần nhớ: space = 32, '0' = 48, 'A' = 65, 'a' = 97. Mã 0–31 và 127 là ký tự điều khiển (không in được).
  • Pixel xám 8-bit: 0 là đen tuyền, 255 là trắng tinh, 128 là xám giữa.

Cách chơi

  • Mỗi vòng cho một byte (8 bit).
  • Unsigned: cộng trọng số của các bit 1.
  • Two's complement: nếu bit đầu là 0 thì giống unsigned. Nếu là 1 thì lấy unsigned − 256.
  • ASCII: chọn ký tự ứng với mã đó, hoặc chọn "không có ký tự in được".
  • Pixel xám: chọn ô xám có độ sáng đúng.
  • Mỗi kính đúng +5 điểm, đúng cả 4 kính thưởng thêm +5.
  • Each round gives you one byte (8 bits).
  • Unsigned: add up the weights of the 1 bits.
  • Two's complement: if the first bit is 0 it equals unsigned. If it is 1, take unsigned − 256.
  • ASCII: pick the character for that code, or "no printable character".
  • Gray pixel: pick the swatch with the right brightness.
  • +5 per correct lens, +5 bonus when all 4 are right.
