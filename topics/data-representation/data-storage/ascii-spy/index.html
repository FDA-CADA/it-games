Cách chơi

  • Giải mã: đổi từng byte ra số (hệ 2 hoặc hệ 16), tra bảng ASCII, gõ ký tự vào ô bên dưới. Mốc: 'A' = 65, 'a' = 97, '0' = 48.
  • Mẹo 0x20: chữ hoa và chữ thường chỉ khác nhau đúng một bit. Bấm vào bit để lật, dùng càng ít lần lật càng tốt.
  • Tiếng Việt: thử mã hóa "Kinh tế Quốc dân" bằng ASCII và xem điều gì xảy ra.
