Cách chơi

  • Giải mã: đổi từng byte ra số (hệ 2 hoặc hệ 16), tra bảng ASCII, gõ ký tự vào ô bên dưới. Mốc: 'A' = 65, 'a' = 97, '0' = 48.
  • Mẹo 0x20: chữ hoa và chữ thường chỉ khác nhau đúng một bit. Bấm vào bit để lật, dùng càng ít lần lật càng tốt.
  • Tiếng Việt: thử mã hóa "Kinh tế Quốc dân" bằng ASCII và xem điều gì xảy ra.
  • Decode: turn each byte into a number (base 2 or 16), look it up in the ASCII table, and type the character below. Anchors: 'A' = 65, 'a' = 97, '0' = 48.
  • The 0x20 trick: upper and lower case differ in exactly one bit. Click bits to flip them, using as few flips as possible.
  • Vietnamese: try encoding "Kinh tế Quốc dân" (National Economics University) in ASCII and see what happens.
