4 bits give exactly 16 patterns, arranged on a wheel from 0000 to 1111. Your job: label each pattern with its value under each integer representation.

Cách chơi

  • Unsigned: 4 bit là giá trị 0 … 15.
  • Sign-and-magnitude: bit đầu là dấu (0 = +, 1 = −), 3 bit sau là độ lớn.
  • Two's complement: bit đầu có trọng số −8 thay vì +8. Ví dụ 1101 = −8 + 4 + 1 = −3.
  • Xếp đúng ngay lần đầu +6 điểm, xếp đúng sau khi đã sai +2 điểm.
  • Level cuối: hai vòng đặt cạnh nhau, trả lời 6 câu hỏi so sánh (+10 mỗi câu đúng ngay lần đầu).
  • Unsigned: 4 bits hold the values 0 … 15.
  • Sign-and-magnitude: the first bit is the sign (0 = +, 1 = −), the other 3 bits are the magnitude.
  • Two's complement: the first bit weighs −8 instead of +8. For example 1101 = −8 + 4 + 1 = −3.
  • +6 for a label placed right the first time, +2 if it took more tries.
  • Last level: the two wheels side by side and 6 comparison questions (+10 each when right first time).
