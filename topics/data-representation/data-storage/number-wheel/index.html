Cách chơi

  • Unsigned: 4 bit là giá trị 0 … 15.
  • Sign-and-magnitude: bit đầu là dấu (0 = +, 1 = −), 3 bit sau là độ lớn.
  • Two's complement: bit đầu có trọng số −8 thay vì +8. Ví dụ 1101 = −8 + 4 + 1 = −3.
  • Xếp đúng ngay lần đầu +6 điểm, xếp đúng sau khi đã sai +2 điểm.
  • Level cuối: hai vòng đặt cạnh nhau, trả lời 6 câu hỏi so sánh (+10 mỗi câu đúng ngay lần đầu).
