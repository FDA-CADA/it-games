🔎 Zoom War

Có hai cách lưu hình ảnh. Raster (bitmap: JPG, PNG) lưu một lưới điểm ảnh. Vector (SVG, PDF, font chữ) lưu công thức hình học: đường thẳng, đường cong, màu tô.

There are two ways to store a picture. Raster (bitmap: JPG, PNG) stores a grid of pixels. Vector (SVG, PDF, fonts) stores geometry: lines, curves and fill colours.

Ở kích thước bình thường, hai loại trông y hệt nhau. Zoom vào thì mới biết ai là ai.

Cách chơi

  • Ai vỡ trước? Kéo thanh zoom (hoặc bấm ▶ Zoom liên tục) rồi chỉ ra hình nào là raster. Raster độ phân giải càng cao thì càng phải zoom sâu.
  • Dung lượng: tính và so sánh kích thước file raster với vector.
  • Chọn định dạng: mỗi tình huống nên dùng raster hay vector?
  • Mỗi câu đúng ngay lần đầu +10 điểm.
  • Who breaks first? Drag the zoom slider (or press ▶ Keep zooming) and say which picture is raster. The higher the raster resolution, the deeper you must zoom.
  • File size: compute and compare raster and vector file sizes.
  • Pick the format: raster or vector for each situation?
  • +10 for every answer right on the first try.
