✉️ XOR Secret Messenger

XOR có một tính chất kỳ diệu: (P ⊕ K) ⊕ K = P. XOR tin nhắn P với khóa K là ra bản mã C, rồi XOR C với cùng khóa là ra lại P. Cùng một phép toán dùng cho cả mã hóa lẫn giải mã.

XOR has a magical property: (P ⊕ K) ⊕ K = P. XOR a message P with a key K to get the ciphertext C, then XOR C with the same key to get P back. One operation does both encryption and decryption.

0 ⊕ 0 = 00 ⊕ 1 = 11 ⊕ 0 = 11 ⊕ 1 = 0

Quy tắc nhớ: giống nhau ra 0, khác nhau ra 1.

Rule of thumb: same gives 0, different gives 1.

Cách chơi

  • Bấm vào các bit để đặt kết quả XOR, rồi Kiểm tra (Enter). Các bit sai được tô đỏ.
  • Level 3–4: gõ ký tự của tin nhắn đã giải mã vào các ô. Mốc ASCII: 'A' = 65 = 01000001, 'a' = 97.
  • Đúng ngay lần đầu +10, đúng sau khi sửa +4.
  • Chơi theo cặp: ở màn hình đầu, bấm "Mở máy mã hóa".
  • Click bits to set the XOR result, then Check (Enter). Wrong bits turn red.
  • Levels 3–4: type the characters of the decrypted message into the boxes. ASCII anchors: 'A' = 65 = 01000001, 'a' = 97.
  • +10 if right first time, +4 after corrections.
  • Play in pairs: on the start screen, press "Open the cipher machine".
